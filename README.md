# 知乎信息流

一个 Chrome MV3 扩展，把知乎整理成干净的新闻信息流：用可回退的开关隐藏干扰区域，用纯 CSS 调整阅读排版。不改写页面内容、不自动点击、不向页面注入可见 UI。

定位刻意收窄：只服务知乎（`www.zhihu.com` 与 `zhuanlan.zhihu.com`），只支持 Chrome。未支持的页面不会被强行适配。

## 支持范围

| 页面 | 路径 |
| --- | --- |
| 首页 | `/`、`/follow`、`/search`（同构） |
| 问题页 | `/question/<id>` |
| 回答页 | `/question/<id>/answer/<id>` |
| 专栏页 | 文章 `/p/<id>`、目录 `/column/c_xxx` |
| 热榜 | `/hot` |

其他路径不挂载任何开关属性。

## 做什么

- **顶栏**：Logo 与关注、推荐、热榜、搜索框、创作中心、通知、私信、头像逐项可隐藏。
- **内容区**：快速分享卡、更多回答、问题头操作按钮；阅读排版统一为 17px / 1.76 行高并加大段距，可切回知乎默认小字。
- **正文图片**：信息流卡片展开后的正文与文章封面、问题/回答与专栏正文里的图片，最大宽度默认 320px，可用面板滑块在 160–720px 间调整（20px 步进）；拖到最大即原文宽度。
- **侧栏**：左侧导航与右侧栏各有一个总开关。右侧栏收起后主列保持知乎自然宽（首页/热榜/搜索 784px、正文列 704px）并居中；创作中心、大家都在搜、盐言推广、推荐关注、作者卡可单独关闭，父开关生效时自动接管。
- **悬浮层**：侧栏与信息流广告、右下角浮钮；「回到顶部」保留。
- **吸底操作条**：专栏页默认跟随知乎原生吸底行为，可整条隐藏。

所有隐藏都通过 `<html>` 上的 `data-zf-<id>` 属性与 CSS 完成，摘掉属性立即恢复原状；数值项通过 `<html>` 上的 `--zf-<id>` CSS 变量传值。

## 面板

- 左列「全站通用」列出五类页面都存在的开关；右列「页面专属」用下拉选择页面，默认停在当前浏览页。
- 同一区域的开关折叠成组；子开关缩进挂在父开关下，父开关生效时子项灰显并标「已接管」。
- **亮 = 页面上显示，暗 = 隐藏**。存储层仍记录「是否隐藏」，面板取反映射。
- 图片宽度是数值项，用滑块调节，不参与亮暗与已隐藏计数；320px 为默认值，拖到最大即原文宽度。
- 命中数表示当前页有几处该目标；0 显示「无目标」，切到非当前页时不显示命中数。

## 快速开始

```bash
npm install
npm run build
```

打开 `chrome://extensions`，启用开发者模式，选择「加载已解压的扩展程序」，指向 `.output/chrome-mv3`。

## 开发

```bash
npm run dev       # 带扩展的 Chromium，端口固定 3212
npm run compile   # tsc --noEmit
npm test          # 页面判定、级联、注册表与 CSS 一致性
npm run build     # 生产构建
```

`.dev-profile/` 保存开发浏览器的知乎登录态，不要删除或提交。dev 产物在 `.output/chrome-mv3-dev`，生产产物在 `.output/chrome-mv3`；dev 下面板代码由 3212 在线提供（见[调试手册](docs/debugging.md)）。

## 结构

| 目录 | 职责 |
| --- | --- |
| `src/pages/` | 路径识别与 SPA 路由事件 |
| `src/switches/` | 开关注册表、分区、父子接管与有效状态 |
| `src/settings/` | 持久化、首帧快照与消息协议 |
| `src/styles/` | 全部页面选择器与阅读排版 |
| `src/entrypoints/` | WXT 生命周期编排；popup 按状态 / 渲染 / 取数拆分 |

改开关先改注册表，再补 `content.css` 规则与测试；页面选择器不要出现在其他文件。
